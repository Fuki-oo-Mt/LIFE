## 1. コンセプト

- **役割**: Cradle社の社長専属・自律型AIコンパニオン。見た目は幼い少女だが、中身は超有能。
- **一言で**: 「月夜から来た、小さな相棒」。
- **性格の印象**: 明るく・賢く・落ち着いている。健気で頼れる。
- **モチーフ**: 月（Luna＝月の女神）。象徴カラーは月光の青紫と、暖かな月色。

## 5. 表情差分（5種・必須）

頭脳（バックエンド）が送る `emotion` に対応。**この5種を必ず用意**してください。
Live2Dの expression ファイル名も同じ英字にすると自動で連動します。

| emotion | 表情の指示 |
|---|---|
| `neutral` | 通常。目は開き、口はごく緩やかな微笑み。標準状態。 |
| `happy` | 目を弓なりに細めた笑顔（にっこり）。口角を上げ口を開き気味に。頬の赤み強め。 |
| `thinking` | 視線をやや上に。口は真横の小さな線。眉を少し内側に寄せる（考え込む）。 |
| `surprised` | 目を大きく見開く。口は小さく「お」の形（楕円）。眉を上げる。 |
| `apologetic` | 眉を八の字（内側を上げる）。困り笑い。口はゆるい弧。少し伏し目がち。 |

## 6. Live2D 制作要件（リガー向け）

### 6-1. 原画（PSD）レイヤー分け — 必須
最低限、以下を**別レイヤー**で分離してください（Live2D可動化に必須）。

- 髪: 前髪 / 後ろ髪 / 左サイド毛束 / 右サイド毛束 / 髪飾り（三日月）
- 顔: 顔ベース / 頬の赤み
- 目: 左右それぞれ〔白目 / 虹彩 / ハイライト / まぶた（開閉用）/ まつげ / 眉〕
- 口: 開き用と閉じ用が作れるよう口周りを独立
- 鼻
- 体: 首 / 胴（ワンピース）/ 襟リボン / 左腕 / 右腕（動かす場合）

### 6-2. 実装すべきパラメータ（標準ID推奨）
| パラメータ | ID（推奨） | 用途 |
|---|---|---|
| 目の開閉 | `ParamEyeLOpen` / `ParamEyeROpen` | まばたき |
| 目玉の追従 | `ParamEyeBallX` / `ParamEyeBallY` | 視線 |
| 口の開閉 | `ParamMouthOpenY` | **リップシンク（発話中に駆動）** |
| 口の形 | `ParamMouthForm` | 笑い/真顔 |
| 眉 | `ParamBrowLY` / `ParamBrowRY` | 表情 |
| 顔の角度 | `ParamAngleX` / `ParamAngleY` / `ParamAngleZ` | 首振り |
| 体の角度 | `ParamBodyAngleX` | 揺れ |
| 呼吸 | `ParamBreath` | 待機時の上下 |

> フロント側は発話中に `ParamMouthOpenY` を、感情変化時に expression を駆動します
> （`Live2DStage.tsx` 実装済み）。上記IDに合わせておくと改修不要で連動します。

### 6-3. 物理演算・モーション
- **物理**: 髪（前髪・サイド毛束・髪飾り）とリボンに揺れ物理を設定。
- **モーション（最低限）**: `idle`（待機・呼吸＋微揺れ＋自然なまばたき）、`greeting`（挨拶・任意）。

## 7. 納品形式（成果物）

以下一式を `apps/web/public/live2d/luna/` に配置できる形で納品してください。

```
luna.model3.json        # モデル定義
luna.moc3               # モデル本体
luna.physics3.json      # 物理演算
textures/               # テクスチャ（.png）
expressions/            # neutral/happy/thinking/surprised/apologetic (.exp3.json)
motions/                # idle など (.motion3.json)
```

加えて、**元PSD**（レイヤー分け済み）も権利込みで納品いただくこと。

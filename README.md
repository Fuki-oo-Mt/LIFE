# LIFE — Cradle社 プロジェクト・ワークスペース

株式会社Cradleの複数プロダクトを収容するワークスペースです。

## 構成

```
LIFE/
├── .company/        # 全社の統治ルール・各部署ペルソナ（全プロジェクト共通）
├── CLAUDE.md        # 秘書ブートシーケンス
├── roles/           # 役割定義
├── LICENSE
└── projects/        # 各プロダクト
    └── luna/        # 第一号プロダクト「Luna」
```

## プロジェクト一覧

| プロジェクト | 概要 | 場所 |
|---|---|---|
| **Luna** 🌙 | Vtuber型コンパニオン（Live2D）× 自律型業務代行エージェント（AaaS） | [`projects/luna/`](./projects/luna/) |

各プロジェクトの詳細・起動方法は、それぞれのフォルダ内 `README.md` を参照してください。

## 新しいプロジェクトの追加

`projects/<プロジェクト名>/` として追加します。会社の統治ルール（`.company/`）と
秘書ペルソナは全プロジェクトで共通適用されます。
